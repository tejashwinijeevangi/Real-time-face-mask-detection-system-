# Real-Time Face Mask Detection System

## 📌 Project Overview

The **Real-Time Face Mask Detection System** is a Deep Learning mini project that aims to identify whether a person is wearing a face mask. The project explores the application of Deep Learning and computer vision techniques for face mask detection.

The system analyzes face images and classifies them into two categories: **Mask** and **No Mask**. This project demonstrates how intelligent vision-based systems can help automate face mask detection.

## 🎯 Objectives

- To understand the fundamentals of Deep Learning and computer vision.
- To develop a system for detecting face masks in images.
- To classify faces into Mask and No Mask categories.
- To explore the practical application of image processing and deep learning techniques.

## ✨ Features

- Face mask classification.
- Image-based analysis using Deep Learning techniques.
- Classification into Mask and No Mask categories.
- Practical implementation through a Jupyter Notebook.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Domain:** Deep Learning
- **Environment:** Google Colab / Jupyter Notebook
- **Notebook:** `DL_project.ipynb`

## ⚙️ Project Workflow

1. **Data Preparation:** Prepare face images for analysis.
2. **Data Processing:** Process images into a suitable format for the model.
3. **Model Development:** Apply Deep Learning techniques for face mask classification.
4. **Prediction:** Classify images into Mask or No Mask categories.
5. **Result Analysis:** Examine the classification results.

## 🚀 How to Run the Project

### Option 1: Google Colab

1. Open the `DL_project.ipynb` notebook in this repository.
2. Download the notebook or open it in Google Colab.
3. Upload or connect the required dataset if prompted.
4. Install any dependencies required by the notebook.
5. Execute the notebook cells in order to run the project.

### Option 2: Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/tejashwinijeevangi/Real-time-face-mask-detection-system-.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Real-time-face-mask-detection-system-
   ```

3. Install Jupyter Notebook if necessary:

   ```bash
   pip install notebook
   ```

4. Launch the notebook:

   ```bash
   jupyter notebook DL_project.ipynb
   ```

5. Install any additional libraries required by the notebook and execute the cells in order.
